# Welcome to my web Portfolio

Hi, I'm Franco Romanelli, a student and junior developer. I'm currently focused on expanding my knowledge in technology and web development.

## Getting Started

The first thing I did was create the necessary file and folder structure for the project. To build the foundation, I mainly relied on my knowledge of HTML and CSS, courses I had previously taken, and the experience I gained from other projects.

The initial HTML and CSS structure was developed entirely by me from scratch. From that foundation, I gradually built the portfolio's structure and visual design.

## Project Evolution

Once the initial structure was completed, I started adding different visual details, improving the code organization, and experimenting with new tools and technologies.

Throughout the process, I also used AI tools such as ChatGPT, Claude, and Gemini as support for solving problems, researching alternatives, identifying bugs, and improving specific parts of the code.

I also experimented with technologies and approaches that I don't fully master yet, such as Tailwind CSS. This allowed me to discover new ways of working while also identifying the tools and technologies I want to continue learning.

The idea is to keep developing the portfolio step by step, adding new sections, improving the design, and optimizing the code.

## Use of Artificial Intelligence

Artificial intelligence was mainly used as a support tool throughout the development process.

I used it to:

-   Solve questions and understand concepts.
-   Find and fix bugs.
-   Analyze and simplify parts of the code.
-   Explore different design alternatives.
-   Experiment with technologies I'm still learning, such as Tailwind CSS.

The goal was not to completely delegate the development process, but rather to use these tools as support while learning and building the project.
